# Polling App AI Rules

1. Place all authentication-related pages under `/app/auth/` (e.g., `/app/auth/login/page.tsx`)
2. Use `react-hook-form` + `zod` for every form validation
3. Use `shadcn/ui` components (Button, Input, Card) styled with Tailwind
4. Access Supabase only through `@/lib/supabaseClient.ts`
5. Always include error handling with `try/catch` for Supabase queries
6. Use server components by default; use client components only when necessary (e.g., for forms, state management)
7. Use `useRouter` from `next/navigation` for client-side navigation
8. Use `next/font` to load and optimize fonts
9. Write unit and integration tests for all core logic; place tests in `/tests`
10. Add JSDoc/TSDoc comments to all exported functions and components
11. Ensure all UI components are accessible (ARIA, keyboard, contrast)
12. Use TypeScript everywhere and define reusable types/interfaces
13. Document all required environment variables in `.env.example`
14. Use ESLint and Prettier for code quality; run checks before commits
15. Sanitize and validate all user input on both client and server
